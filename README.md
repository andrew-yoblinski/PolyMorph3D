# PolyMorph3D
A flexible MATLAB-based tool for quantifying microglia morphology and multi-colocalization in three dimensions.

PolyMorph3D is a script-based MATLAB program mediated by graphical user interface (GUI) apps; thus, coding experience is not necessary. The user starts with a 3D stack (which must be TIFF), threshold and identify valid structures within channels, then colocalize structures from up to 4 channels with the identified microglia. After processing a single image manually with the Main Script, a parameters file is saved and may be used for batch processing many TIFF images.
